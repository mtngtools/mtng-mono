# Auth

Identity, sessions, access control, and auth-related APIs across mtngTOOLS apps.

## Scope

- Authentication strategy (who/what issues and verifies identity)
- Session/token model and lifecycle
- Role/permission model — relation to `applRole` (attend, admin, integ) in [`core/spec/app-env.md`](../../packages/core/spec/app-env.md)
- Per-endpoint authorization conventions for Nitro/Nuxt server routes
