# Livestream resource assignment

Assigning livestream/playback resources to sessions or rooms.

## Scope

- Relation to the [timeline & steps](../../../../patterns/timeline-steps/README.md) `set-to-live` step, which requires playback info "typically from resource assignment on session's room"
- Provider-specific playback info shape
- Assignment cardinality and inheritance (room-level default vs per-session override)
